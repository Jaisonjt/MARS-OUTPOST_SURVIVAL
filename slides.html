05 / TECHNICAL ARCHITECTURE & CODE HIGHLIGHTS

Pure-Function Core & Resilient UI Engineering

Immutable Pure-Function Reducer

gameState.js

Decouples math from DOM rendering and clamps meters between 0 and 100.

case ACTIONS.MAKE_DECISION: {
  const choice = eventObj.choices.find(
    (c) => c.id === action.choiceId
  );
  const updated = applyEffects(
    state.game, choice.effects
  );
  return deepFreeze({ ...state,
    game: { ...updated,
      currentEvent: null } });
}
